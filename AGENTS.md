# Agent entry point

Read [.ai4x/BEHAVIOR.md](.ai4x/BEHAVIOR.md), then
[.ai4x/CONTEXT.md](.ai4x/CONTEXT.md) and [.ai4x/STATE.md](.ai4x/STATE.md).
If present, read ignored `.yap/cfg/session.md` afterwards for private local review
navigation. It must not be published or treated as additional authority.

Fresh sessions recover through these files without resume, old chat or a special
startup command. A status greeting reports the current state and waits; a
continuation greeting follows the authorized return point. BEHAVIOR defines both.
An explicitly selected portfolio owns its own instructions and authored content.
